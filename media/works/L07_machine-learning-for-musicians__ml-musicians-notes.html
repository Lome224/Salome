Midterm experiment · Machine learning for musicians

Music Genre
Classification

A midterm experiment in using a convolutional neural network to classify music from mel-spectrograms. The project explores how patterns in an audio signal can support music classification, and where genre boundaries remain difficult for a model to distinguish.

From sound to prediction

Separate Python notebooks cover audio preprocessing, CNN training and genre prediction. The classifier learns from ten genres in the GTZAN collection: blues, classical, country, disco, hip-hop, jazz, metal, pop, reggae and rock.

Examining the results

The study includes a confusion matrix and an analysis of commonly confused genre pairs, treating errors as part of understanding what the model has learned.

Notebooks and documentation

The download contains the original midterm implementation, including preprocessing, training and inference notebooks, screenshots and project documentation. Python dependencies, the dataset and trained model are required to reproduce the experiment; consult the included README for those resources.
